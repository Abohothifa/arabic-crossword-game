# تحدي الكلمات المتقاطعة — لعبة كلمات متقاطعة عربية

لعبة ألغاز ذهنية عربية كاملة: شبكات كلمات متقاطعة حقيقية ومترابطة،
4 مستويات، 10 تصنيفات، تحدي يومي، عملات ومساعدات، إنجازات وإحصائيات،
مكافأة يومية، ووضع ليلي/نهاري. تعمل دون إنترنت تماماً.

تطوير وبرمجة: HessamX 2026
حسام إكس © 2026

## المحتوى

- 24 لغزاً، 136 كلمة — كل لغز شبكة 9×9، وكل كلمة تتقاطع مع غيرها
  في الحرف الصحيح (متحقق برمجياً عبر `tools/validate_levels.py`).
- المستويات: المبتدئ (6 ألغاز)، المتوسط (6)، المتقدم (6)، الخبير (6).
- التصنيفات: الثقافة الإسلامية، التاريخ والحضارات، الجغرافيا والدول
  والعواصم، العلوم والاكتشافات، الحيوانات والنباتات، الرياضة،
  اللغة العربية، الشخصيات التاريخية، المعلومات العامة، الألغاز والأحاجي.

## تشغيل نسخة الويب

الطريقة الأسرع — افتح الملف مباشرة في المتصفح:

```
web/index.html
```

أو من سطر الأوامر (من داخل مجلد `web/`):

```
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح. لا تحتاج اللعبة إلى أي
اتصال بالإنترنت، ويُحفظ تقدمك وعملاتك في `localStorage` في المتصفح.

## بناء APK في Android Studio

1. افتح مجلد `android/` في Android Studio.
2. انتظر مزامنة Gradle (يحتاج إنترنت أول مرة لتحميل الإضافات فقط).
3. من القائمة: Build ← Build App Bundle(s) / APK(s) ← Build APK(s).
4. سيظهر ملف APK في `android/app/build/outputs/apk/debug/app-debug.apk`.

للبناء من سطر الأوامر (بعد تثبيت JDK 17 وAndroid SDK):

```
cd android
export ANDROID_HOME=/opt/android-sdk   # أو مسار الـ SDK عندك
./gradlew assembleDebug
```

ملاحظة: نسخة الويب داخل `android/app/src/main/assets/web/` هي نسخة
من ملفات `web/`، فإذا عدّلت الويب انسخ الملفات إلى هناك قبل البناء.

## إضافة مراحل جديدة

المراحل بيانات، وليست كوداً: عدّل `web/levels.json` (وأضف نسخة البيانات
المضمّنة في `app.js` إن كنت تعتمد على فتح الملف مباشرة)، ثم شغّل:

```
python3 tools/validate_levels.py
```

يجب أن ينجح التحقق 100% قبل النشر: كل تقاطع يطابق الحرف نفسه،
وكل كلمة تتقاطع مع غيرها، ولا إجابات أو تلميحات مكررة.
لتوليد مراحل جديدة من الصفر: `python3 tools/generate_levels.py <seed>`.

## المساعدات والعملات

- رصيد البداية: 100 عملة. إكمال لغز أول مرة: +30، وعند الإعادة: +10.
- معنى إضافي: 5 عملات — كشف حرف: 10 — حذف الحروف الخاطئة: 15 — حل الكلمة: 30.

## حالة APK

- **لم يُنتَج ملف APK في هذه الدورة**، بعد محاولتين جادتين للبناء.
- ما تم تثبيته بنجاح: JDK 17، Gradle 8.7، Android SDK
  (cmdline-tools، platform-tools، platforms;android-34، build-tools;34.0.0).
- سبب الفشل (المحاولتان بنفس الخطأ، قبل أي تجميع أو تحميل تبعيات):
  Gradle لا يستطيع استقبال أول رسالة من الـ daemon عبر مقبس localhost:
  `Could not receive a message from the daemon` — سببه
  `IllegalArgumentException: Unexpected type tag 109 found`
  في `DefaultSerializerRegistry`. الـ daemon نفسه يبدأ ويستمع على
  `127.0.0.1`، لكن عميل Gradle يفشل في قراءة رسالته في هذه البيئة
  المعزولة (المحاولة 1: وضع daemon العادي، المحاولة 2: `--no-daemon`
  مع تجميع Kotlin داخل العملية وتنظيف سجل الـ daemon — نفس النتيجة).
- لم يُصنع أي APK وهمي، ولم يُدَّعَ أي نجاح.
- الحل المتوقع: بناء المشروع في Android Studio على جهاز حقيقي
  (كما في قسم «بناء APK في Android Studio» أعلاه)، فالمشروع كامل
  وصحيح البنية، و`AndroidManifest.xml` بلا إذن إنترنت، و`MainActivity`
  تعرض ملفات محلية فقط.
